# technical-documentation.md

1. Project Overview

This project is a personal portfolio website developed using HTML, CSS, and JavaScript. The website is designed to introduce myself, display my projects, and provide a contact form for visitors.

The website is responsive, meaning it can adjust to different screen sizes, including desktops, tablets, and mobile phones.

2. Technologies Used

The following technologies were used to develop the website:

HTML: Used to create the structure and content of the website, including the About Me, Projects, and Contact sections.

CSS: Used to design the website, including colors, fonts, spacing, and responsive layouts.

JavaScript: Used to add interactive features, such as switching between dark and light modes and displaying messages when submitting the contact form.

Visual Studio Code: Used as the code editor to develop and organize the project files.

GitHub: Used to store and manage the project files.

3. Project File Structure

The project is organized into the following files:

index.html: Contains the main structure and content of the website.

css/styles.css: Contains the styling and responsive design rules.

js/script.js: Contains the JavaScript code for interactive features.

README.md: Provides the project description, setup instructions, and a summary of AI usage.

docs/technical-documentation.md: Explains the technical details of the website.

docs/ai-usage-report.md: Documents how AI tools were used during development.

4. Website Features

About Me Section

This section introduces me and provides a short description of my background and interests. It also includes a button that takes visitors to the Projects section.

Projects Section

This section displays two projects with their titles and descriptions. CSS Grid is used to organize the projects into a responsive layout.

Contact Section

This section includes a contact form where visitors can enter their name, email address, and message. JavaScript is used to check the input fields and display a confirmation message.

The contact form is a demonstration and does not send messages to a server.

Dark and Light Mode

The website includes a button that allows users to switch between dark and light modes. JavaScript changes the CSS class of the page to update its appearance.

Responsive Design

The website uses CSS Flexbox, Grid, and media queries to adjust its layout based on the screen size. This allows the website to display properly on desktops, tablets, and mobile phones.

5. Code Organization

The website code is separated into three main files to make it easier to understand and maintain.

HTML handles the website content and structure, CSS controls the design and layout, and JavaScript handles user interactions.

The files are connected through the HTML document using the stylesheet link and JavaScript script tag.

6. Testing and Verification

The website should be tested to make sure all features work correctly.

The main tests include:

Checking that navigation links move to the correct sections.

Testing the dark/light mode button.

Checking that the contact form displays the correct messages.

Resizing the browser window to check the responsive design.

Making sure the website displays correctly without broken links or errors.

7. Limitations

The website currently uses only front-end technologies and does not have a backend or database.

The contact form displays a confirmation message but does not send or store the information.

The website can be improved in the future by adding more projects, additional features, and a working contact system.
