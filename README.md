Project description: This project is a personal portfolio website created using HTML, CSS, and JavaScript. The purpose of this website is to introduce myself, showcase my projects, and provide a way for visitors to contact me. The website includes three main sections: About Me, Projects, and Contact. It also supports responsive design and includes a dark mode feature to improve the user experience.

To run this project locally:
1. Download the project files from the GitHub repository.
2. Extract the downloaded ZIP file.
3. Open the project folder using Visual Studio Code.
4. Open the index.html file in any web browser.
5. The website will run locally without requiring additional software or dependencies.
